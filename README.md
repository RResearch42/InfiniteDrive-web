# INFINITE DRIVE

A community guide to the
Infinite Drive ecosystem.

**Live site:** https://infinitedrive42.xyz

## About

A single-page guide to the Infinite Drive
ecosystem: official links, chain data,
network settings, projects, and builder
resources, all in one place.

This guide is created and maintained by
just one member of the community. While
every care has been taken with the
information here, this is not an official
Infinite Drive site.

For official resources, see the
Deep Thought Labs GitHub:
https://github.com/deep-thought-labs

Just the guide. Not financial advice.

## Wallet safety

- This site has no wallet connection
  anywhere. It never asks you to connect
  a wallet or sign anything.
- It never asks for your seed phrase or
  private keys.
- "Add Network" simply opens Chainlist
  (chainlist.org) in a new tab.
